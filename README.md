## 🚀 O projekte

WebBridge.ai je moderné Enterprise SaaS riešenie pre slovenský trh, ktoré vytvára bezpečné "mosty" medzi firemnými SQL databázami a umelou inteligenciou (Gemini API). Naša filozofia je jasná: **"Nekradneme dáta, dávame im mozog."**

### 🎯 Cieľové odvetvia
- ⚖️ **Právnické kancelárie** - Inteligentná analýza zmlúv a precedentov
- 🚚 **Logistika a doprava** - Optimalizácia trás a predikcia dopytu
- 🏢 **Interné systémy** - Jednotné AI rozhranie pre firemné databázy

## 🚀 Ako spustiť

### Lokálne spustenie

1. **Klonujte repozitár**
   ```bash
   git clone https://github.com/WebBridge-ai/WebBridge.Ai.git
   cd WebBridge.Ai
   ```

2. **Otvorte v prehliadači**
   - Jednoducho otvorte `index.html` vo vašom prehliadači
   - Alebo použite lokálny server:
   ```bash
   # Python 3
   python -m http.server 8000

   # PHP
   php -S localhost:8000

   # Node.js (s http-server)
   npx http-server
   ```

3. **Prejdite na**
   ```
   http://localhost:8000
   ```

## 🔧 Customizácia

### Zmena farieb
Upravte CSS premenné v `css/style.css`:
```css
:root {
    --primary: #667eea;
    --secondary: #764ba2;
    --accent: #f093fb;
    /* ... */
}
```

### Pridanie sekcií
1. Pridajte HTML do `index.html`
2. Štylujte v `css/style.css`
3. Pridajte interaktivitu v `js/main.js`
