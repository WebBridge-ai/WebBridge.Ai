01

Vektorová vrstva

Použitie pgvector pre natívnu SQL sémantickú analýzu priamo vo vašej databáze

🗄️

pgvector - Native SQL Vector Extension

WebBridge.ai využíva pgvector, open-source PostgreSQL extension pre ukladanie a vyhľadávanie vektorových embeddingov priamo vo vašej databáze. Žiadne externé vector stores nie sú potrebné.

  • ✓ Native PostgreSQL integrácia
  • ✓ ACID compliance pre vektorové operácie
  • ✓ Podpora pre L2 distance, cosine similarity, inner product
  • ✓ Až 2000 dimenzií na vektor
⚡

Optimalizované indexovanie

Pre maximálny výkon používame pokročilé indexovacie algoritmy HNSW (Hierarchical Navigable Small World) a IVFFlat (Inverted File with Flat compression).

  • ✓ HNSW index pre sub-sekundové vyhľadávanie
  • ✓ IVFFlat pre memory-efficient ukladanie
  • ✓ Automatická optimalizácia query plánov
  • ✓ Podpora pre partial indexing
🔍

Sémantické vyhľadávanie v SQL

Kombinujeme silu tradičného SQL s pokročilým sémantickým vyhľadávaním. Používatelia môžu kombinovať vector similarity s klasickými WHERE klauzulami.

  • ✓ Hybridné dotazy (SQL + vector similarity)
  • ✓ Filtrovanie pred vector search pre efektivitu
  • ✓ Ranking podľa semantic relevance
  • ✓ Support pre multi-vector queries
🔄

Real-time Embedding Pipeline

Automatická vektorizácia nových dát pri INSERT/UPDATE operáciách pomocou PostgreSQL triggers a background workers.

  • ✓ Automatické generovanie embeddingov
  • ✓ Asynchronné spracovanie pre high throughput
  • ✓ Incremental updates bez downtime
  • ✓ Custom embedding models support
💡

Technická výhoda

Vďaka pgvector zostávajú vaše dáta a embeddingy v jednej transaktional databáze. To zjednodušuje architektúru, eliminuje synchronizačné problémy a garantuje data consistency pomocou ACID transactions.

02

Security Stack

Multi-layer bezpečnosť: TLS 1.3, AES-256 šifrovanie a Zero Data Retention na strane LLM

🔐

Transport Layer Security (TLS 1.3)

Modern Cryptographic Protocol

Všetka komunikácia medzi vašou databázou a WebBridge gateway používa TLS 1.3 – najnovšiu verziu Transport Layer Security protokolu s vylepšenou bezpečnosťou a výkonom.

TLS 1.3 Perfect Forward Secrecy 0-RTT Resumption ChaCha20-Poly1305

Cipher Suites

Podporujeme len moderné, bezpečné cipher suites bez známych zraniteľností. Deprecated algoritmy (SHA-1, RC4, MD5) sú zakázané.

AES-256-GCM AES-128-GCM ECDHE-RSA
🗝️

AES-256 Encryption at Rest

Database Encryption

Všetky dáta uložené v databáze môžu byť šifrované pomocou AES-256 v režime GCM (Galois/Counter Mode) s AEAD (Authenticated Encryption with Associated Data).

AES-256 GCM Mode AEAD Key Rotation

Key Management

Enterprise-grade správa šifrovacích kľúčov s podporou pre HSM (Hardware Security Modules) a pravidelnou key rotation.

HSM Support KMS Integration Automated Key Rotation
🚫

Zero Data Retention (ZDR) na strane LLM

Žiadne ukladanie na LLM serveroch

Zero Data Retention politika: Vaše dáta sa nikdy neukladajú na serveroch Google Gemini API. Všetky queries sú spracované v reálnom čase a okamžite vymazané po doručení odpovede.

Zero Persistence In-Memory Processing Only No Training on Your Data Immediate Deletion

Contractual Guarantees

Zmluvné záruky s Google Cloud o nezadržiavaní vašich dát. Vaše dotazy nie sú používané pre trénovanie modelov ani pre iné účely.

DPA (Data Processing Agreement) No Model Training GDPR Compliant
🔒

End-to-End Security

Od vašej databázy až po LLM response: každý krok je zabezpečený. Dáta sú šifrované v pohybe (TLS 1.3), v pokoji (AES-256) a nikdy nie sú persistované na externých serveroch (ZDR).

Plná Architektúra systému

Privátna RAG architektúra s izolovaným tokom dát

Vaša SQL Database

PostgreSQL, MySQL, MSSQL

WebBridge Gateway

Vektorizácia + Query Processing

Gemini 1.5 Pro

Private LLM Gateway

End User

Web / API Interface

1. Data Extraction

Pripojenie k vašej databáze cez bezpečný TLS 1.3 tunel. Dáta sa extrahujú len v čase spracovania query a nikdy sa neukládajú.

// Read-only connection
$connection = DB::secure('your_db')
->readOnly(true)
->encrypted(true);

2. Vektorizácia

Textové dáta sa transformujú na vektorové embeddingy pomocou pgvector (PostgreSQL) priamo vo vašej databáze.

// Vector embedding locally
$vectors = VectorEngine::embed($data)
->inMemory(true)
->persist(false);

3. LLM Processing

Kontext sa posiela do Gemini 1.5 Pro cez privátnu API bránu. Model dostáva len relevantný kontext, nie celú databázu.

// Context-aware query
$response = Gemini::query($context)
->maxTokens(2048)
->temperature(0.3);

4. Response Delivery

Odpoveď z LLM sa doručí používateľovi cez šifrovaný kanál. Celý proces prebehne v reálnom čase bez persistencie.

// Secure delivery
return $response
->encrypted()
->toUser($authenticated);
